# dsh-whale-voyage · 大肥鱼出海

给 DeepSeek Harness 养一只放养的小鲸鱼。它在港口里歇够了就自己出海，逛真实的互联网，回港时寄给你一张明信片，带回一件「土特产」——它真的看到、觉得你会喜欢的东西，附原链接。一张明信片只介绍一样东西。

- **港口**：左侧栏「出海」。看它在不在家、去了哪片海、什么时候回来。
- **塞纸条**：写上你想让它留意的东西（比如「agent 记忆」）。它会揣着出门，七成时候照着找，剩下的时候按自己的兴趣逛。
- **明信片**：可爱插画风，大肥鱼是主角，每片海有一个主景物和一件小配饰（星星、草帽、小花、水手帽、眼镜）。每张画的都是「这一趟」：回港时刻定天色，天气和姿势各不相同，带回的那样东西会变成画里的一个词（房子的门牌、一条弹幕、一个对话气泡、论文标题）。正文是它用你 DSH 的模型写的，土特产只从它真实取到的条目里挑，不编造。
- **明信片册 / 海图**：收过的明信片都在册子里；去过的海会在海图上点亮。
- **谷时靠岸**（可选）：写明信片要调一次模型。打开后，如果回港时赶上 DeepSeek 高峰（北京时间工作日 9–12、14–18 点），它会在港外等到谷时再靠岸。
- **快速模式**（试玩）：航程和休息都缩短到 1–2 分钟。

## 五片海

| 海域 | 取材 | 能用纸条关键词 |
|---|---|---|
| 代码群岛 | GitHub 最近 3–14 天新建、星数靠前的仓库（每趟随机换时间窗和页码） | 能 |
| 论文深海 | arXiv 最新的 AI / NLP / ML 论文 | 能 |
| 弹幕湾 | B 站综合热门 | 不能 |
| 黑客海峡 | Hacker News 首页 | 能 |
| 闲聊礁 | V2EX 今日热议 | 不能 |

都是免 key 的公开接口。某片海连不上（比如网络访问不了 Hacker News），它会自动绕去别的海，并记住这片海 24 小时：这期间很少再挑它、绕路时也排在最后，海图上标「最近起雾」；五片都连不上就「起雾」，寄回一张空手的明信片。带回过的链接不会再带第二次。

## 安装

```sh
dsh plugin --profile web add dsh-whale-voyage
```

本地开发版：

```sh
dsh plugin --profile web add link:/path/to/dsh-whale-voyage
dsh --profile web
```

## 用到的模型

写明信片用 DSH 的默认模型（`agentDefaultModel`）。默认路线没有凭据时（比如新建配置默认走 API key、而你是账号登录），会改用 DeepSeek 账号路线 `deepseek-account / deepseek-flash`。都不可用时用内置的模板话写明信片，土特产照常带回。每次回港最多调一次模型，输出上限 1200 token；模型有 none / minimal / low 这类低推理档时用低档，没有就用模型默认档。

## 时间怎么走

航程在 DSH 开着时推进。DSH 关着期间到点的航程，下次启动时一次结算，只寄一张。状态存在 `$DSH_HOME/plugin-data/dsh-whale-voyage/state.json`（默认 `~/.dsh`）。

## 结构

| 文件 | 作用 |
|---|---|
| `voyage.js` | 航程核心（不依赖 DSH）：海域取材、挑海、峰谷时段、明信片提示词与解析、模板兜底 |
| `index.js` | 宿主半区：存档、10 秒一次的时间推进、调模型写明信片，挂 `GET /api/dsh-whale-voyage/state` 和 `POST /api/dsh-whale-voyage/action` |
| `client.js` | 浏览器半区：侧栏入口（有新明信片时亮小点）、港口画面、明信片（SVG 插画）、册子、海图、设置 |
| `test/` | `npm test` |

写接口只接受同源、带 `x-whale-voyage: 1` 头的请求。
